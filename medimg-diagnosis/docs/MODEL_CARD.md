# Model card - DenseNet121 chest X-ray classifier

**FOR EDUCATION ONLY - NOT FOR CLINICAL USE.**

## Intended use
Teaching how an AI-assisted reading workflow (DICOM -> model -> explanation -> human review -> audit) fits together.
**Not** for diagnosis, triage, screening, or any patient-care decision.

## Model
DenseNet121, ImageNet-pretrained, final linear layer for 8 labels (Atelectasis, Cardiomegaly, Effusion,
Infiltration, Mass, Nodule, Pneumonia, Pneumothorax), multi-label sigmoid, BCE with class-prevalence `pos_weight`.
Input 224x224, grayscale replicated to 3 channels, ImageNet normalisation. Explanations: Grad-CAM on the final
feature map (7x7, bilinearly upsampled - coarse by design).

## Data
NIH ChestX-ray14 (Wang et al., 2017): 112,120 frontal images, 30,805 patients. **Labels are NLP-mined from reports**
(estimated accuracy >90% by the authors, but noisy, esp. Infiltration/Nodule/Mass). Split by patient 80/10/10 using a
hash of the patient ID; default experiment uses 30% of patients.

## Limitations
* Single source institution (NIH Clinical Center); **no external validation** - expect performance drop elsewhere.
* Noisy NLP labels cap achievable AUROC and make label-level claims unreliable; "Infiltration" is especially vague.
* Frontal PA/AP only; paediatric, lateral, portable/ICU-device images and rare diseases are under-represented.
* Scores are **uncalibrated** model outputs; they are not probabilities of disease.
* Grad-CAM shows where the network's gradient is concentrated, **not** proof of causal reasoning. Heatmaps can
  highlight shortcuts (text markers, chest tubes, pacemakers, scanner artefacts). Failure cases are generated by
  `evaluate.py` into `reports/failure_cases/` - include them in the presentation.
* Resizing to 224px loses small findings (nodules, small pneumothorax).
* Model has not been tested on DICOM-derived pixels from different vendors; windowing differs from PNG training data.

## Bias & fairness
Evaluate AUROC by sex and age band (done in `evaluate.py`; report gaps with confidence intervals). Race/ethnicity
and socioeconomic data are not in NIH metadata, so those disparities **cannot be measured** here - this is itself a
limitation, not evidence of fairness. Known literature shows CXR models can encode race and can under-diagnose
under-served groups.

## Human oversight & accountability
The radiologist must Approve/Reject each result; the decision, reviewer, model version, scores and comment are written
to a hash-chained audit log. The UI shows a persistent banner and watermark; API responses include a disclaimer.

## Privacy
Patient name is never stored; patient ID is stored only as a truncated SHA-256. The demo uses synthetic IDs. Do not load real patient data into this demo stack (no auth/encryption).
